# 📊 Retail Department & Category Performance Dashboard | Power BI

## 📌 Project Overview
This project focuses on analysing retail department and category performance using Microsoft Power BI. The dashboard provides insights into sales distribution, customer metrics, regional performance, and category-level trends.

Developed as part of my Data Analytics Fellowship at DataMelon Labs, this project helped me strengthen my skills in data analysis, DAX, and interactive dashboard development.

## 🎯 Objectives
- Analyse overall department performance.
- Evaluate sales performance across product categories.
- Understand category-wise sales contribution.
- Explore regional sales distribution.
- Analyse monthly sales trends.
- Compare category performance across different store formats.

## 📈 Dashboard Highlights
- **Department Performance:** Overview of key sales and customer metrics.
- **Category Analysis:** Compare sales across product categories.
- **Sales Contribution:** Understand how categories contribute to overall sales.
- **Regional Analysis:** Explore sales distribution across regions.
- **Monthly Trends:** Track sales performance over time.
- **Store Format Analysis:** Compare category mix across store formats.
- **Interactive Visualisations:** Explore business metrics using charts, matrices, and filters.
